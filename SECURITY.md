# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.2.x | ✅ |
| < 1.2 | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Send a private message on [Telegram (@Bitologist)](https://t.me/Bitologist) with a description and steps to reproduce.
You'll get a reply within a few days, and a fix will be released as soon as possible.

Umbra stores Spotify API keys and settings locally in `%APPDATA%\Umbra\settings.json` — they are never uploaded anywhere.
