# Contributing

Thanks for helping make Umbra better!

1. Fork and create a branch: `git checkout -b feature/my-idea`
2. `pip install -r requirements.txt` and run `python main.py`
3. Keep the style: PySide6, painted widgets, no external UI assets; run `python -m pyflakes umbra` before committing.
4. Open a pull request describing what changed (screenshots welcome for UI changes).

Bugs and ideas: [open an issue](https://github.com/sadult/umbra/issues).
